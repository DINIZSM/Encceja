
# Curso de Matemática para o ENCCEJA

Este é um curso interativo de Matemática criado por Rodrigo Diniz do Prado. O curso é voltado para quem deseja se preparar para o ENCCEJA, abordando os principais tópicos de Matemática.

## Como rodar o projeto

1. Clone o repositório.
2. Execute `npm install` para instalar as dependências.
3. Execute `npm run dev` para rodar o servidor de desenvolvimento.
